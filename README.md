# CaptainPBX issues

This repository is where you report bugs and ask for features in **CaptainPBX**. It does not contain the product. The installer, license, and overview essays are in [captainpbx-distro](https://github.com/captainpbx/captainpbx-distro).

**Contact:** [crew@captainpbx.com](mailto:crew@captainpbx.com).

CaptainPBX is free to use as provided. The name, logo, and other marks are not licensed for rebranding. See the license in the distro repository.

## Open an issue

Use [Issues](https://github.com/captainpbx/captainpbx-issues/issues) for:

- A bug on an installed appliance
- A feature request
- A question about how a shipped behavior works, after you have read the essay in the distro repository

One topic per issue. Search open issues before you file a duplicate.

### Bug

Include:

- The installer image you used, and the SHA256 from [RELEASES.md](https://github.com/captainpbx/captainpbx-distro/blob/master/RELEASES.md) if you have it
- What you did, what you expected, and what happened
- Whether you are a platform admin or inside one tenant
- Logs or screenshots that show the failure

Do not paste passwords, SIP secrets, API tokens, or private keys. Captain Audit stores those as `[redacted]` for the same reason.

### Feature request

Say who it is for (platform admin, tenant admin, or a portal user), what you cannot do today, and how you would know the feature works. A request is not a commitment to build it.

## Sponsorship

CaptainPBX has no user cap and no paid tier. Sponsorship is optional support for the people who write the software, review issues, and publish installer images.

Sponsorship does not buy a different license, a private build, priority ownership of the roadmap, or the right to use the CaptainPBX name on another product.

When GitHub Sponsors is turned on for this organization, sponsor from the [captainpbx](https://github.com/captainpbx) profile. Until that button is available, a thoughtful issue or a tested fix discussion is still a real contribution.
